# Generated Model Checkpoints

Running `03_tiny_vit_digits_demo.ipynb` creates `tiny_vit_mnist.pt` in this directory. The checkpoint contains the trained model weights, architecture configuration, class names, normalization settings, random seed, and measured test accuracy used by `04_visualize_vit_decision.ipynb`.

Generated `.pt` files are ignored by Git. Run Notebook 03 before Notebook 04 whenever the checkpoint is absent or you want to visualize a newly trained model.
