# ReAct Pattern Instructions

Implement an iterative reasoning, action, and observation loop. This implementation must be separate from the Planning Pattern implementation.

## Required Comparison

Reimplement this pattern in the one agent framework selected for the final project. For at least three test cases, run both the instructor-provided ReAct implementation in `src/` and your reimplementation. Use the same user question, data, LLM/model, configuration, and success criterion for both runs. If you use more than one LLM/model, document and compare the models under the same conditions.

Complete and run `react.ipynb` for this pattern.

## Required Evidence

- Research question and an evidence-based answer.
- Setup/dependencies, source location, run command, and reproduction instructions.
- Iteration log, actions, and observations.
- Instructor-baseline and student-implementation run records and comparative results.
- Limitations, failures, and proposed mitigations.

Store the evidence in this folder or link to it from the final report.
