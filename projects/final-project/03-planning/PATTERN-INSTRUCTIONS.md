# Planning Pattern Instructions

Implement a workflow that creates an explicit plan, executes its steps, records observations, and replans when observations change the investigation or task.

## Required Comparison

Reimplement this pattern in the one agent framework selected for the final project. For at least three test cases, run both the instructor-provided Planning implementation in `src/` and your reimplementation. Use the same user question, data, LLM/model, configuration, and success criterion for both runs. If you use more than one LLM/model, document and compare the models under the same conditions.

Complete and run `planning.ipynb` for this pattern.

## Required Evidence

- Research question and an evidence-based answer.
- Setup/dependencies, source location, run command, and reproduction instructions.
- Initial plan, execution/observation log, and revised plan.
- Instructor-baseline and student-implementation run records and comparative results.
- Limitations, failures, and proposed mitigations.

Store the evidence in this folder or link to it from the final report.
